# Дорожная карта

## Ближайшие этапы и требуемые стенды

Перед каждым аппаратным набором объявляются плата, отладчик, сервер и соединения.
Подтверждены два одновременно подключённых стенда: **BlackPill F411 + ST-Link** и
**BluePill F103 + J-Link**, оба по SWD. Пока оставляем оба; UART/VCOM не требуется.
Физическое переключение отладчиков — только после подтверждения владельца.

1. **F411 + ST-Link / OpenOCD и ST server**: завершено, одинаковый ELF, 24/24 на
   каждом сервере, ADC/Sleep/manifest/HAL и timeout/recovery проверены.
2. **F411 + J-Link**: после согласованной смены проводки добавить device mapping
   и повторить общий набор/отказные проверки; контракты F411 уже адаптированы.
3. **F103 + ST-Link**: после согласованной смены проводки повторить новые manifest/HAL
   механизмы через OpenOCD/ST server. Старые результаты этого не доказывают.
4. До смены проводки можно продолжать выделение модуля и расширение контрактов на
   действующих F411/ST-Link и F103/J-Link. Проверить отдельный проект-потребитель.
5. Stop/watchpoints/наблюдение без halt планировать отдельными наборами.

| Плата | ST-Link / OpenOCD | ST-Link / ST server | J-Link / J-Link server |
| --- | --- | --- | --- |
| F103 BluePill | 24/24 до manifest/HAL изменений | 24/24 до manifest/HAL изменений | 24/24 с manifest/HAL; текущий стенд |
| F411 BlackPill | 24/24 с ADC/Sleep/manifest/HAL; recovery | 24/24 на том же ELF; recovery | Не проверено; mapping ещё не добавлен |

Это матрица проверенных комбинаций, а не обещание одинаковых возможностей.
OpenOCD с адаптером J-Link — отдельная потенциальная комбинация, пока вне плана.
H503 остаётся отложенным до сообщения владельца. Порядок этапов можно изменить
по доступности стендов, сохраняя явное объявление и подтверждение переключений.
