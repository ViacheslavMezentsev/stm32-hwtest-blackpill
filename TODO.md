# Дорожная карта

## Ближайшие этапы и требуемые стенды

Перед каждым новым аппаратным набором агент сообщает плату, отладчик, сервер и
соединения. Текущий подтверждённый стенд: **BluePill F103 + J-Link, SWD**.
Его оставляем подключённым. UART/VCOM не требуется. При физической смене стенда
аппаратные действия начинаются только после подтверждения владельца.

1. **BluePill + J-Link / J-Link GDB Server**: manifest с привязкой к ELF реализован;
   семь выборочных HAL-контрактов и отказные случаи проверены. Этап завершён;
   расширение контрактов оставлено в общем плане ниже.
2. **BlackPill F411 + J-Link / J-Link GDB Server**: после согласованной замены
   добавить явное отображение MCU в backend; адаптировать HAL-контракты профиля и повторить общий набор, включая
   ещё не проверенные на F411 пересчёт ADC и Sleep. Успех F103 не переносить на F411.
3. **BlackPill F411 + ST-Link / OpenOCD и ST GDB Server**: после подтверждения
   смены отладчика сравнить один и тот же ELF и набор сценариев через два сервера.
4. **BluePill F103 + ST-Link / OpenOCD и ST GDB Server**: при следующем согласованном
   возвращении выполнить регрессию новых manifest/HAL-проверок для завершения матрицы.
5. Выделение модуля и новые методы периферии: выбирать один базовый стенд для
   разработки, затем повторять затронутые проверки на других комбинациях.
   Stop/watchpoints/наблюдение без halt планировать отдельными наборами.

| Плата | ST-Link / OpenOCD | ST-Link / ST server | J-Link / J-Link server |
| --- | --- | --- | --- |
| F103 BluePill | 24/24 до следующих изменений | 24/24 до следующих изменений | 24/24; текущий стенд |
| F411 BlackPill | Исходные 17 HW; новые ADC/Sleep ожидают проверки | Не проверено | Не проверено; mapping ещё не добавлен |

Это матрица проверенных комбинаций, а не обещание одинаковых возможностей.
OpenOCD с адаптером J-Link — отдельная потенциальная комбинация, пока вне плана.
H503 остаётся отложенным до сообщения владельца. Порядок этапов можно изменить
по доступности стендов, сохраняя явное объявление и подтверждение переключений.
