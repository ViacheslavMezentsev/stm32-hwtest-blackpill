# Первичная аппаратная проверка BlackPill

## Объём

Проверена Debug-прошивка GCC 13.3.1 на WeAct BlackPill v3 (STM32F411CEU6),
подключённой к WeAct ST-Link v2 по SWD. Это этап проверки платы и инструментов,
а не готовая реализация всей архитектуры `HWTEST_ARCHITECTURE.md`.
Release и GCC 14/15 пока проверены только сборкой.

Перед реализацией изучены `../buck-boost-course/99_BOARD_TEST/CMakeLists.txt`,
`Tests/test_runner.cmd`, `Tests/.gdbinit`, CMake набора BOARD_TEST_01,
Python-сценарии ADC 01_01/02/03 и примеры USART/SPI/clock из наборов 02/03/10.
Сохранены остановки на функциях, чтение символов и инъекция ошибки HAL.
Убраны зависимость от J-Link/двух МК, зашитые номера пробников, подавление stderr
и использование HAL tick как единственного таймаута. После `return HAL_ERROR`
не вызывается `finish`, поскольку текущим кадром уже становится вызывающая функция.

## Инструменты и подключение

- STM32CubeCLT 1.22.0 установлен в `%LOCALAPPDATA%/Programs/STM32CubeCLT_1.22.0`.
- Внутри него: STM32CubeProgrammer CLI 2.23.0 и нативный ST-LINK GDB server
  (последний в этом прогоне не использовался).
- OpenOCD 0.12.0; xPack GCC 13.3.1, GDB-Python с Python 3.11.4.
- ST-Link firmware V2J43M28; Windows видит Debug interface и VCOM (в этом сеансе COM13).
- STM32 Device ID 0x431, Rev A, Flash 512 КБ, питание около 3.24 В.
- CubeProgrammer при запросе 1000 кГц выбирает 950 кГц.
- OpenOCD подключается без переустановки драйвера. Его штатный reset-скрипт F4
  запрашивает 2000 кГц, адаптер выбирает 1800 кГц и пишет об этом в лог.

Серийный номер пробника передаётся аргументом и не хранится в Git.

## Повторный запуск в PowerShell

Собрать и прошить (команда записи действительно заменяет прошивку):

```powershell
cmake --preset debug
cmake --build --preset debug
$programmer = "$env:LOCALAPPDATA/Programs/STM32CubeCLT_1.22.0/STM32CubeProgrammer/bin/STM32_Programmer_CLI.exe"
& $programmer -l stlink-only
$probeSerial = '<серийный номер из списка>'
& $programmer -c port=SWD "sn=$probeSerial" freq=1000 -w build/debug/stm32-hwtest-blackpill.elf -v -rst -run
```

Запустить тест на уже прошитой плате:

```powershell
python tools/hardware_smoke.py --serial $probeSerial
```

Раннер рассчитан на Windows и Python 3.11+. Он берёт OpenOCD из PATH, GDB-Python
из стандартного каталога xPack GCC 13 в папке пользователя. Есть параметры
`--openocd`, `--gdb`, `--elf`, `--timeout` (по умолчанию 30 секунд на GDB).
Каталог запуска: `build/hardware-smoke/<UTC timestamp>/`; там находятся
`server.log`, `gdb.log`, `result.json`, сгенерированный из выбранного ELF `image.bin`
и, при аварийном восстановлении, `recovery.log`.

Раннер не прошивает плату. Он сравнивает Flash с BIN, заново полученным из того же
ELF через objcopy, включая Flash-образ начальных значений `.data`.
JSON содержит SHA-256 ELF и BIN, ожидаемые/фактические значения и итоговый статус.
Коды выхода: 0 — PASS, 1 — FAIL проверки, 2 — ERROR инфраструктуры или таймаут.
Отсутствующая плата является ошибкой; автоматического SKIP здесь нет.

На время теста не запускать другую отладочную сессию: файловая блокировка
защищает только от второго экземпляра этого раннера, а не от сторонних программ.
OpenOCD слушает выделенный порт для GDB; Tcl/Telnet отключены. Раннер завершает только
созданные им процессы. После обычного завершения агент делает reset/run;
при таймауте хост пробует восстановить запуск отдельным GDB-подключением.
Неудача восстановления сохраняется как ERROR, а не скрывается.

## Результаты

| Проверка | Результат |
| --- | --- |
| Запись ELF и проверка чтением CubeProgrammer | PASS |
| Совпадение Flash и образа | PASS |
| Достижение main после сброса и loop после инициализации | PASS |
| SystemCoreClock 16 МГц; SYSCLK HSI; AHB /1; APB1/APB2 /2 | PASS |
| GPIOC clock; PC13 output, push-pull, no-pull, low-speed | PASS |
| PC13 ODR: начальный 0, затем 1 и 0 | PASS |
| Продвижение uwTick между вызовами loop | 501 и 501 мс |
| Принудительный HAL_ERROR из HAL_RCC_OscConfig → Error_Handler | PASS |
| Несовпадающий ELF, без его прошивки | Отклонён, ERROR / код 2 |
| Принудительный таймаут 0.01 с | ERROR / код 2, host recovery reset/run |
| Обычный прогон после таймаута | PASS |
| Повторное подключение CubeProgrammer после завершения раннера | PASS, core running |

Для отрицательной проверки использовалась временная копия ELF с изменённым байтом
образа в `build/`; она не записывалась в плату. Код прошивки ради тестирования
не менялся. Плата оставлена исполнять обычное мигание после сброса.

Измерение uwTick показывает время по HAL, а не точность периода физического сигнала:
точки останова влияют на реальное время. Чтение ODR подтверждает программное
переключение выхода, но не доказывает свечение светодиода или электрические уровни.
В GDB 13 встречается нефатальное предупреждение преобразования CP1252 → UTF-32;
оно сохранено в логах, проверкам не мешает.
