# Результат цикла DDTT

Дата: 2026-10-10. Модуль v0.4.0 (`9c3ff2d`), Windows/ST-Link/OpenOCD 0.12.0.

Требование: при таймауте уведомления ADC установить диагностический код 6 до platform_error.
На обеих платах исходное значение — 0, после исправления — 6. Новый сценарий не менялся:
отключает IRQ DMA, подтверждает срок не менее 100 тиков и отсутствие публикации.
Дополнительно обновлено прежнее ожидание подавленного callback (0 → 6): это принятое изменение
диагностики приложения, а не обход нового теста. Коды платформы 1..5 сохранены.

F411CE и F401CC: по 23/23 host, 22/22 аппаратных сценария; BOOT/GPIO восстановления — по 2/2 PASS.
