# MMIO/SVD в BlackPill

[English](MMIO_SVD.en.md)

Модуль закреплён на 8fdbb58be35689376a70eb1973bea7096de6f45d — финальный кандидат 0.5.0,
API 3. Изменения ядра не требуются. Обычные сценарии def остаются синхронными.
22 идентификатора сценариев и исходники прошивки сохранены.

Оба профиля подключают [проектный SVD](../hil/common/stm32f4-test.svd) через
[mmio].svd в session.toml. Это минимальное описание 40 регистров и заводских
значений для данных сценариев, а не полный SVD производителя.
Адреса 37 элементов сверяются с CMSIS в ELF через GDB без target remote;
три адреса калибровок — отдельным host-тестом с board.toml и константами
DS9716/DS10314. Права и эффекты описаны по RM0368/RM0383 и PM0214.
Сверка адресов не доказывает правильность модели побочных эффектов.

## Обращения и очистка

| Объект | Правило сценария |
| --- | --- |
| RCC, GPIO, TIM, RTC, ADC, DMA, SCB | Чтение через t.mmio.read; маски CMSIS вычисляются без чтения периферии |
| NVIC ISER/ICER | W1S/W1C: готовая маска, allow_effects=True, без автоматического readback |
| SCB ICSR | Только маска PENDSTCLR, не read-modify-write всего регистра |
| SysTick CTRL | Чтение с allow_effects=True снимает COUNTFLAG; сохраняются только биты управления |
| ADC CR2 | Явное согласие на запись; при отказе возвращается изменённый ADON |
| DMA Stream0 | NDTR/M0AR меняются при EN=0; после инъекции EN снимается и проверяется до восстановления |
| Заводские значения | Только чтение 16 бит; SRAM, аргументы и состояние приложения остаются в обычном API |

ICER в проектном SVD намеренно write-only: аппаратное чтение возможно, но состояние
сценарии читают через ISER. ADC DR отмечен readAction=clear, DMA LIFCR — write-only/W1C,
TIM SR — W0C. Запись без явного согласия на описанные эффекты отвергается до транспорта.
Это не гарантия единственной физической транзакции на шине за GDB-сервером.

try/finally начинается до первой изменяющей операции. Host-модель проверяет частичную
установку, потерю подтверждения, исключение наблюдения и отказ остановки DMA.
Если EN не снят после восьми явных чтений, восстановление NDTR/M0AR запрещается,
ошибка сохраняется. Для сна обе маски IRQ восстанавливаются даже при отказе первой записи.
Это возврат изменённых настроек, а не откат времени, COUNTFLAG, pending, отсчётов или
полного состояния периферии. На стенде F411CE пройдены все 22 сценария; аппаратная приёмка F401CC ещё впереди.

## Офлайн-маршрут

    cmake --preset f411ce-hil -DSTM32_GDBTEST_STAND=
    cmake --build --preset f411ce-hil
    ctest --preset f411ce-hil-host --output-on-failure

Для второго профиля заменить f411ce на f401cc. На каждый профиль: 22 prepare,
host.traceability, host.mmio (12 проверок), host.svd_elf — всего 25 CTest.
CI дополнительно собирает Debug/Release и запускает native ADC; проверяет стиль сценариев.
HIL сохраняет неиспользованные отладочные типы для сверки CMSIS; тестовых hooks нет.
Лимит records поднят до 256 из-за MMIO intent/result и повторов WFI.

Windows/Linux проверяют сборку, prepare, права/эффекты, очистку, inspect из другого cwd
и сохранность SVD при pack/open_package. PASS этих проверок не является HW PASS.
Аппаратные результаты до миграции не подтверждают новый транспорт MMIO.
